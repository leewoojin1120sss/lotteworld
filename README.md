# 롯데월드야호

서울 롯데월드 어드벤처를 위한 모바일·PC 지도. 첨부된 **2026 국문 가이드맵**의 원본 조감도와 공식 공개 웹 정보를 사용합니다.

- B1·1F·2F·3F·4F·매직아일랜드 지도, 확대·축소·드래그·핀치 조작
- 가이드맵의 어트랙션 42개, 식당·카페 53개, 샵·체험 21개 및 편의시설 기호 132개
- 계단·엘리베이터·에스컬레이터·화장실·의무실·AED 등 종류별 필터와 전체 층 검색
- 공식 웹 카탈로그의 추가 장소와 해당 원본 위치 지도, 탑승 제한 및 공식 상세 링크
- GPS 수신 좌표·오차 확인, 선택한 층에 내 위치 직접 지정, 일회성 위치 링크 공유
- 같은 층의 참고 동선, 즐겨찾기 브라우저 저장, 첫 방문 후 오프라인 가이드맵
- 공식 대기 API 수신·주기 갱신. 빈 응답은 미제공, 5분 지난 값은 만료 처리

## 실행과 검증

Node.js 22 이상. 패키지 설치가 필요 없습니다.

```sh
npm test
npm run check
npm run build
python -m http.server 8000 --directory dist
```

GPS는 HTTPS 또는 localhost에서 사용합니다. 위치 권한은 버튼을 눌렀을 때만 요청합니다. 위치는 브라우저 메모리에만 두며 서버·GitHub·분석 서비스로 전송하거나 저장하지 않습니다. 사용자가 누른 공유 기능만 지도 좌표·층·공유 시각 및 최근 수신 GPS를 링크의 fragment에 담습니다. 링크를 받은 사람은 해당 순간의 위치를 확인합니다. 실시간 위치 추적은 없습니다.

## GitHub Pages

저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택하면 `.github/workflows/site.yml`이 테스트·빌드·배포합니다. 이 최초 설정에는 저장소 관리 권한이 필요하며 `GITHUB_TOKEN`으로 사이트를 새로 활성화할 수 없습니다. 설정 후 Actions에서 이 워크플로를 다시 실행할 수 있습니다.

실행 시각은 KST 10:03–22:58 사이 5분 간격 대기 API 갱신, 매일 08:47 전체 카탈로그 갱신입니다. GitHub 예약 실행은 지연될 수 있어 정확한 실시간성을 보증하지 않습니다. 변경된 JSON은 별도 봇 커밋에 보존하고 같은 실행에서 배포합니다. API 실패 시 기존 성공 시각을 바꾸지 않고 대기 수치를 비웁니다. API 키나 별도 서버는 필요 없습니다.

## 자료와 정확도

가이드맵은 측량 평면도가 아닌 기울어진 조감도입니다. GPS 위경도를 임의의 선형 변환으로 조감도에 찍지 않습니다. 층과 조감도의 위치는 사용자가 지정하며, GPS는 실제 위경도·오차를 별도로 보여줍니다.

보행 참고선은 가이드맵에 그려진 통로를 수작업으로 옮긴 것입니다. 같은 층의 연결만 지원하며 실측 거리·분 단위 소요시간·무장애 경로·통제 구간을 보증하지 않습니다. 서로 다른 층의 승강기와 계단을 근거 없이 연결하지 않습니다.

1F 파스퇴르밀크바(푸드 22번), 4F 전망대게임장(샵 16번)은 원본 목록에 있으나 지도 번호가 빠져 있습니다. 4F 샵 17번은 원본에 중복되어 있습니다. 목록과 주의 문구를 보존하며 위치를 지어내지 않았습니다. 범례에 없는 기호는 기타 편의시설로 표시합니다. 원본 자체의 현장 누락 여부까지 보증할 수 없습니다.

공식 API의 별도 위치 지도는 `570 × 427` 표시 좌표계입니다. 해당 원본 지도에만 공식 핀을 표시하며 PDF에 좌표를 혼용하지 않습니다. 파크 밖 쇼핑몰·주변 시설은 공식 원본 JSON에 보존하지만 메인 파크 검색 목록에 섞지 않습니다. 시설 정보·메뉴·운영 상태는 공식 안내와 현장 확인이 우선입니다.

API 경로·응답 형식·실제 확인 결과는 [docs/API.md](docs/API.md)에 기록했습니다. 공개 웹 구현용 API는 장기 제공 계약이 확인된 API가 아니므로 변경 시 연동 코드를 점검해야 합니다.

지도·시설 사진·공식 정보의 권리는 롯데월드 등 원권리자에게 있습니다. 롯데월드가 운영하거나 보증하는 공식 서비스가 아닙니다.

## 파일

`index.html`, `styles.css`, `app.js`: 화면과 상호작용. `lib.js`: 공유 검증·만료 처리·경로 계산. `data/park.json`: PDF 목록과 좌표. `data/walkways.json`: 참고 통로. `scripts/sync_official.py`: 공식 공개 데이터 연동. `scripts/extract_guide.py`: 원본 PDF에서 지도·기호 재생성. `assets/guide-2026.pdf`: 원본 가이드맵 내용 보존본.

# 롯데월드야호

서울 롯데월드 어드벤처를 위한 모바일·PC 지도. 첨부된 **2026 국문 가이드맵**의 원본 조감도와 공식 공개 웹 정보를 사용합니다.

- B1·1F·2F·3F·4F·매직아일랜드 지도, 원본 벡터 글자·기호를 보존한 SVG 확대·축소·드래그·핀치 조작
- 가이드맵의 어트랙션 42개, 식당·카페 53개, 샵·체험 21개 및 편의시설 기호 132개
- 계단·엘리베이터·에스컬레이터·화장실·의무실·AED 등 종류별 필터와 전체 층 검색
- 공식 웹 카탈로그의 추가 장소와 해당 원본 위치 지도, 탑승 제한 및 공식 상세 링크
- GPS·네트워크 위치 연속 수신, 실내 신호 점프 완화, 실제 좌표 기준점을 이용한 조감도 위치 추정
- 층 직접 선택, 현장 위치 보정, 선택형 걸음·방향 보조, 추정 범위를 포함한 일회성 위치 공유
- 현위치 출발·목적지 직접 검색, 어트랙션·식당·기념품별 목록
- 다른 층의 목적지는 가까운 계단·에스컬레이터·승강기부터 안내하고, 도착층에서 현위치를 지정해 계속
- 화장실·보조배터리 등은 통로를 따른 거리가 가까운 한 곳 추천
- 즐겨찾기 브라우저 저장, 첫 방문 후 오프라인 가이드맵

## 실행과 검증

Node.js 22 이상. 패키지 설치가 필요 없습니다.

```sh
npm test
npm run check
npm run build
python -m http.server 8000 --directory dist
```

GPS는 HTTPS 또는 localhost에서 사용합니다. 권한은 `내 위치`를 누를 때 요청하며, 층은 사용자가 선택합니다. 1F·매직아일랜드·4F는 공개 지리 좌표로 대략 추정하고 B1·2F·3F는 지도 보정이 필요합니다. 위치·보정값·센서 값은 메모리에만 유지합니다. 위치 공유를 누른 경우만 선택한 좌표·층·추정 여부·범위와 GPS 수신값을 일회성 링크로 전달합니다. 정확한 실내 측위나 자동 층 식별을 보증하지 않습니다. 구현과 검증 범위는 [docs/LOCATION.md](docs/LOCATION.md)에 기록했습니다.

## GitHub Pages

저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**를 선택하면 `.github/workflows/site.yml`이 테스트·빌드·배포합니다. 이 최초 설정에는 저장소 관리 권한이 필요하며 `GITHUB_TOKEN`으로 사이트를 새로 활성화할 수 없습니다. 설정 후 Actions에서 이 워크플로를 다시 실행할 수 있습니다.

공식 장소 카탈로그는 매일 한국 시간 08:47에 갱신합니다. GitHub 예약 실행은 지연될 수 있습니다. 별도 서버나 API 키는 필요 없습니다.

## 자료와 정확도

가이드맵은 측량 평면도가 아닌 기울어진 조감도입니다. GPS 위치는 같은 층의 복수 지리 기준점으로 추정하고 불확실성 범위를 표시합니다. 좌표 기준점은 © OpenStreetMap contributors, ODbL 1.0이며 [data/georeference.json](data/georeference.json)에 개별 출처를 보존합니다. 기준점이 부족한 층은 임의로 다른 층의 변환을 적용하지 않습니다.

보행 참고선은 가이드맵에 그려진 통로를 수작업으로 옮긴 것입니다. 목적지가 다른 층이면 현위치에서 통로를 따라 접근할 수 있는 가장 가까운 이동시설을 먼저 안내하고 종류별 대안도 제공합니다. 목적지 층에 도착한 뒤 사용자가 위치를 갱신하면 최종 동선을 계산합니다. 서로 다른 층의 개별 시설을 검증 없이 연결하지 않습니다. 실측 거리·분 단위 소요시간·무장애 경로·통제 구간은 보증하지 않으며, 통로 연결이 없는 구간은 경로를 만들지 않습니다.

지도 SVG는 원본 PDF의 벡터 글자·번호·기호를 유지하고 조감도 그림은 원본에 내장된 이미지 해상도를 보존합니다. 화면에서 SVG의 실제 너비·높이를 바꾸므로 확대된 비트맵 레이어를 다시 늘리지 않습니다. 그림 자체의 세부 해상도는 원본 한도에 따릅니다. `python scripts/export_vector_maps.py /path/to/original-guide.pdf`로 재생성할 수 있습니다. 방문한 층의 SVG는 오프라인 저장하며, 미방문 층은 작은 WebP 지도로 대체합니다.

2026-11-02 국문·영문 공식 가이드와 대조해 247개 지도 기호의 중심을 검산했습니다. 4F의 중복 17번은 영문 지도에 따라 전망대게임장 16번과 헬로키티 17번으로 분리하고, 1F 악수 기호는 만남의 광장으로 식별했습니다. 1F 파스퇴르밀크바(푸드 22번)는 명확한 가이드 기호가 없어 별도 공식 위치 지도만 제공합니다. [검산 방법·보정 내역·한계](docs/COORDINATES.md)를 기록했습니다.

공식 API의 별도 위치 지도는 `570 × 427` 표시 좌표계입니다. 44×58 원본 핀의 왼쪽 위를 기준으로 배치하고 같은 층의 위치만 연결합니다. 해당 원본 지도에만 공식 핀을 표시하며 PDF에 좌표를 혼용하지 않습니다. 파크 밖 쇼핑몰·주변 시설은 공식 원본 JSON에 보존하지만 메인 파크 검색 목록에 섞지 않습니다. 시설 정보·메뉴·운영 상태는 공식 안내와 현장 확인이 우선입니다.

API 경로·응답 형식·실제 확인 결과는 [docs/API.md](docs/API.md)에 기록했습니다. 공개 웹 구현용 API는 장기 제공 계약이 확인된 API가 아니므로 변경 시 연동 코드를 점검해야 합니다.

지도·시설 사진·공식 정보의 권리는 롯데월드 등 원권리자에게 있습니다. 롯데월드가 운영하거나 보증하는 공식 서비스가 아닙니다.

## 파일

`index.html`, `styles.css`, `readability.css`, `app.js`: 화면과 상호작용. `lib.js`: 위치 공유·경로 계산. `geo.js`: 신호 필터·좌표 추정·걸음 보조. `data/park.json`: PDF 목록과 좌표. `data/walkways.json`: 참고 통로. `scripts/sync_official.py`: 공식 공개 데이터 연동. `scripts/extract_guide.py`: 원본 PDF에서 지도·기호 재생성. `assets/guide-2026.pdf`: 원본 가이드맵 내용 보존본.

### 취향 추천과 위치 지우기

상단 `취향 추천` 또는 모바일 하단 `추천`에서 어트랙션·식당·기념품/체험 취향을 여러 개 선택합니다. 카탈로그 설명의 키워드와 같은 층의 지도 통로 거리를 조합하며 취향 우선·거리 우선·균형을 고를 수 있습니다. 실제 미터 거리·평점·실시간 운영을 보장하지 않습니다. 다른 층은 거리 비교에서 제외하고 이동 필요로 표시합니다. 위치가 없거나 오래된 추정이면 취향만 반영합니다. 선택한 취향은 이 브라우저에 저장합니다.

지도 하단 `위치 지우기` 또는 내 위치 창의 `내 위치 지우기`는 내 핀·오차 범위·현재 경로·보정값을 초기화하고 GPS/걸음 추적을 중지합니다. 공유받은 상대방의 위치는 그대로 남습니다.

### 공식 운휴·점검 배지

어트랙션 목록·상세·길찾기 검색 결과에서 공식 운휴·점검 사유를 표시하고 지도 핀에 표시를 더합니다. 최신 운휴 시설은 추천에서 제외합니다. 공식 정보를 접속 시/화면 활성 중 5분마다 직접 조회하며, 수동 새로 확인과 마지막 확인 시각을 제공합니다. 같은 한국 날짜·30분 이내 자료만 최신으로 취급합니다. 오래되거나 확인할 수 없는 상태는 운행 중으로 단정하지 않습니다. [갱신·실패 처리](docs/API.md#운휴-배지의-브라우저-갱신)를 참고하세요.

### 아이콘 확대 렌더링

지도 배경과 핀 레이어를 최종 화면 픽셀 크기로 배치합니다. 핀의 부모 `scale()`과 자식 역배율 조합을 사용하지 않아 확대 중 글리프가 작은 합성 레이어에서 번지는 것을 방지합니다. 큰 확대에서도 HTML 번호 아이콘을 숨기지 않고 실제 픽셀 크기로 확대해 표시합니다. 불투명 배경으로 원본 인쇄 번호를 덮어 겹침을 줄입니다. 시설 아이콘과 내 위치도 화면 크기 그대로 그립니다.

### 다양해진 취향 추천

어트랙션 10개·음식 12개·기념품/체험 9개의 세부 취향과 카테고리별 상황 묶음 3개를 제공합니다. 설명·메뉴에 확인되는 키워드로 분류하며 가격·평점·식이 제한 등을 추측하지 않습니다. `선택한 취향에 맞는 곳만`, 어드벤처/매직아일랜드 구역, 같은 층, 즐겨찾기 외 장소, 확인된 높이·회전·물·어둠 유형 제외를 조합할 수 있습니다.

관련성과 거리를 우선하되 비슷한 점수에서는 여러 선택 취향과 서로 다른 상점을 섞습니다. `다른 추천 보기`는 조건을 유지하면서 비슷한 후보를 바꾸며 `추천 더 보기`로 나머지 결과를 볼 수 있습니다. 최신 운휴·점검 시설은 계속 제외합니다.

- 확대 아이콘의 덮개 크기는 각 원본 기호의 경계 상자를 기준으로 정한다. 숫자를 숨기거나 부모 레이어를 늘리는 방식은 사용하지 않는다.

공식 영문 가이드도 대조했다. [영문 가이드 원본](https://adventure.lotteworld.com/api/common/download-view-file/download?atchFileId=198ca3d10b42&seq=1)의 SHA-256은 `ed23a58d54d285093afeafeb2be59c7deefafc6c28c5c95d4e2c9e3d37ea3c1e`다.

- 4층 국문 지도에서 두 번 인쇄된 17번: 영문 3쪽에서 아래쪽은 **16 Observatory Game Room**, 위쪽은 **17 Hello Kitty**로 확인된다. 전망대게임장의 위치를 복원하고 헬로키티에 붙어 있던 잘못된 대체 위치를 제거했다. 웹 SVG/WebP의 아래쪽 번호도 16으로 바꿨다. 제공된 PDF 자체는 수정하지 않았다.
- 1층 악수 기호: 국문·영문 2쪽의 지시선과 설명이 **만남의 광장 / Meeting Plaza**를 직접 가리킨다. 기존 ID는 유지하고 이름과 종류를 바로잡았다.

이전 좌표·보정 좌표·원본 도형 경계·PDF 페이지·그리기 순서·이미지 식별값과 출처를 [coordinate-audit.json](../data/coordinate-audit.json)에 기록했다. 동일 PDF를 다시 추출할 때도 이 보정과 식별 결과를 재적용한다.

## 공식 웹 위치 지도

공식 사이트의 공개 API와 실제 JS/CSS, 원본 핀 PNG를 대조했다.

- 표시 캔버스는 **570×427**이다. 매직아일랜드 원본 그림은 2458×2362, 일부 다른 원본은 836×627이지만 API 좌표의 기준 캔버스를 원본 이미지 해상도로 바꾸면 안 된다.
- `pstnXcrd`·`pstnYcrd`는 **44×58 핀 이미지 상자의 왼쪽 위**다. 기존처럼 핀 끝으로 해석하고 `translate(-50%,-100%)` 하면 오프셋이 생긴다. 원본 PNG와 동일한 왼쪽 위 배치·비례 크기로 수정했다.
- `restaurant-59`의 x=-11처럼 음수 시작점도 유효하다. 좌표 파서만 유한한 음수를 허용하며 키 제한·가격 등에 쓰는 비음수 파서는 유지한다.
- 편의시설 API 한 항목에 여러 층/지점이 있다. 첫 번째 지점을 무조건 열지 않고 물리적으로 같은 층만 선택한다. 직접 식별되는 의무실·ATM·베이비라운지·배터리 지점은 ID를 지정한다. 지점 대응을 개별적으로 확인하지 못한 경우 모든 같은 층 후보를 기본 표시하며 순번으로 대응시키지 않는다. 음수 좌표를 보존한 최신 수집 결과 B1 보관함 후보는 3곳, 배터리는 2곳이다.
- 체험샵 API 11개를 별도 `playshop-*` 네임스페이스로 수집한다. 가이드샵 9개의 누락된 공식 연결을 보완한다. 3층 푸드 39의 비스트스테이션/타이탄스낵은 식당 두 개를 함께 연결하며 좌표를 평균하지 않는다.
- 파크 밖 1층, 쇼핑몰 B1 같은 코드를 가이드 1F/B1에 합치지 않는다.

명시적인 장소·지점 연결과 원본 JS/CSS 해시는 [official-links.json](../data/official-links.json)에 있다. 구체적인 API 경로는 [API.md](API.md)를 참고한다.

## GPS 변환 기준점

28개 OSM 노드의 현행 좌표·이름/별칭·버전과 공식 시설의 층을 확인했다. 28개 모두 저장 위경도와 원본이 일치하여 근거 없는 위경도 이동을 하지 않았다. 조감도에서의 목표점만 위에서 검산한 기호 중심으로 갱신했다. 풍선비행의 OSM 이름은 일반적인 ‘풍선기구’이므로 문맥상 대응이며 다른 27개보다 식별 근거가 약하다.

2026-11-05에 변환 계산을 재검산했다. 위경도나 지도 기호를 근거 없이 이동하지 않고, 동일한 기준점에서 거리 가중치를 매끄러운 40m 커널로 바꾸었다. 기준점 하나씩 제외한 예측을 **같은 학습 기준점의 전역 affine 역행렬**로 환산했다. 모델마다 다른 역행렬을 사용하면 실제 PDF 오차가 줄지 않았는데 미터 환산값만 좋아질 수 있기 때문이다.

| 층 | 기준점 | 이전 RMS | 수정 RMS | 이전 최대 | 수정 최대 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1F | 19 | 22.334m | 20.678m | 44.339m | 41.668m |
| 매직아일랜드 | 5 | 31.297m | 29.483m | 44.159m | 43.265m |

PDF 좌표 자체의 RMS도 1F 79.029 → 72.808 포인트, 야외 84.776 → 81.454 포인트로 줄었다. 다만 1F 중앙값은 18.571 → 19.271m로 악화되었다. 동·북 방향으로 인접한 지점들을 통째로 제외한 검증의 1F RMS는 37.519 → 36.054m, 야외는 29.289m로 같았다. 일부 동쪽 구역 제외 검증의 큰 잔차도 보고서에 그대로 남긴다.

이 수치는 **자료와 모델 간 내부 불일치**다. 커널 선택에도 같은 자료를 사용했으므로 독립적인 현장 GPS 검증을 대신하지 않는다. 과거 보고서의 17.552m/29.853m는 서로 다른 국소 역행렬을 쓴 중앙값이어서 위 표와 직접 비교하면 안 된다. 기본 여유 50m를 유지하며 기준점 영역 바깥에서는 여유를 늘린다.

4F 세 점은 짧은 방향 표준편차가 5.03m이고 긴 방향은 57.52m로 거의 일직선이다. 기존 코드는 사용자 보정점에만 배치 검사를 적용했고 공개 기준점에는 적용하지 않았다. 같은 검사를 적용하여 이 불안정한 자동 투영을 중지했다. 4F는 사용자가 현재 지점을 직접 지정할 수 있으며, 충분히 퍼진 사용자 보정점은 별도 검증 후 사용할 수 있다.

이동 중 바뀌는 가중치까지 포함하여 실제 변환의 Jacobian을 계산한다. 지도 핀·오차 타원·걸음 보조가 같은 변환을 사용하고, 한 점 보정의 오프셋도 기준 위치의 동일한 변환에 고정한다. 지원 구역 및 기준점 외곽 50m를 5m 간격 **3,421개 지점**에서 검사해 뒤집힘과 불안정 변환은 0개였다. 실제 재투영으로 구한 미분과 구현의 최대 차이는 0.000117 PDF 포인트/m였다. 중복된 GPS 점프 하나가 두 번의 재획득 신호로 인정되는 문제도 수정했다.

현재 계산과 모든 제외 결과는 [gps-model-audit.json](../data/gps-model-audit.json), 이전 출처 대조는 [georeference-audit.json](../data/georeference-audit.json)에 보존한다.

실제 야외 기준점 세 개(자이로드롭·아트란티스·번지드롭)를 사용한 합성 보정에서 기존 면적 조건을 통과하면서 좌우가 뒤집히는 변환을 재현했다. 다음을 추가했다.

- 거의 일직선인 기준점 배치를 공분산의 두 방향 분산으로 거른다.
- 원래 지도와 방향이 반대인 affine 변환을 거절한다.
- 4개 이상 사용자 기준점은 하나씩 제외하는 검증을 통과해야 한다.
- 세 점만으로 학습한 경우 독립 잔차가 없음을 유지하고 최소 45m 모델 여유를 둔다.
- 미래 시각의 사용자 기준점을 적용하지 않는다.

정확히 기준점을 지나는 삼각형 보간도 검토했으나, 실내 조감도의 일부 삼각형이 뒤집히고 야외 제외 검증도 개선되지 않아 채택하지 않았다. 검증 출처와 재현 수치는 [georeference-audit.json](../data/georeference-audit.json)에 기록했다. 자세한 측위 동작은 [LOCATION.md](LOCATION.md)를 참고한다.

## 재현

```sh
python scripts/audit_coordinates.py /path/to/2026-guide.pdf --output /tmp/coordinate-audit
node scripts/audit_georeference.mjs
node scripts/verify_georeference.mjs  # 공개 OSM 원본을 읽기 전용으로 재대조
python tests/test_sync_coordinates.py

```

`audit_coordinates.py`는 읽기 전용이다. 보정 후 원본 재대조에서 247개 기호의 중심 잔차는 저장 정밀도 기준 0, 편의시설 미대응은 0이었다. 원본 PDF를 재추출하는 경우 `extract_guide.py` 이후 `export_vector_maps.py --refresh-corrected-fallback`을 실행하면 동일한 4층 표기 보정도 다시 적용된다.

통로 참고선과 층간 시설의 실제 연결은 현장 실측 자료가 없다. 기호 중심 보정을 입구·보행 가능 구간의 실측 완료로 해석하지 않는다.

## 2026-11-02 화면·자동 검증 기록

6개 층의 기본 화면에서 배경과 핀 레이어의 원점 차이는 0이었고, 브라우저 반올림을 포함한 핀 중심 배치 차이는 최대 0.021 화면 픽셀 이하였다. 최대 확대에서 숨겨진 번호는 모든 층에서 0개였다. 이는 렌더링 정렬 검사이며 실측 좌표 정확도 수치가 아니다. Node 테스트 42개와 Python 좌표 파서 테스트 2개, 구문·데이터 검사 및 정적 빌드를 통과했다.

390px 모바일 화면에서 가로 넘침이 없고, 4F 샵 16/17 핀이 각 한 개씩 표시되는 것을 확인했다. 야외 의무실의 공식 지도 구역과 B1 보관함 3곳의 기본 동시 표시도 브라우저에서 확인했다.

GitHub Pages의 HTTP 캐시가 이전 파일을 새 오프라인 캐시에 다시 넣는 경우도 보완했다. 새 Service Worker는 핵심 파일을 `cache: reload`로 재검증하고, 등록 시 `updateViaCache: none`을 사용한다. 설치 요청 정책을 별도 회귀 테스트로 확인한다.

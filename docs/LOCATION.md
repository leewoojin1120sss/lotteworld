# 위치 추정 구현

이 기능은 현장에서 측량·검증한 실내 측위 시스템이 아닙니다. 원본 지도는 기울어진 조감도이며, 공개 지리 좌표도 시설 중심점과 실제 입구가 다를 수 있습니다. 화면에는 항상 **추정 위치**와 대략적인 범위를 표시합니다. 층은 사용자가 고릅니다.

## 사용 흐름

`내 위치`를 누르면 기기 위치 권한을 요청하고 연속 수신을 시작합니다. `내가 있는 층`은 지도 열람용 층과 별도로 선택합니다. 다른 층의 지도를 구경하거나 길찾기가 목적지 층을 열어도 실제로 그 층에 도착했다고 가정하지 않습니다.

- 1F·매직아일랜드·4F: 공개 좌표 기준점으로 GPS 위치를 조감도에 대략 투영합니다.
- B1·2F·3F: 지리 기준점이 부족하여 지도에서 현재 위치를 지정해야 합니다. 같은 방문 중 GPS 오차가 40m 이하인 비일직선 보정점 세 개가 충분히 떨어져 모이면 해당 층의 변환을 학습할 수 있습니다. 조건이 충족되지 않으면 추측으로 핀을 만들지 않습니다.
- `이 장소에 있다면 눌러 보정하세요`: GPS로 가까운 기준점을 제시하지만 자동으로 그 장소에 있다고 단정하지 않습니다. 사용자가 실제로 그곳에 있을 때만 선택합니다.
- `지도에서 보정`: 현재 지점을 고릅니다. 최근 GPS 신호가 있으면 같은 층에서 한동안 일정하게 치우친 위치 편차를 보정하는 데 사용합니다.
- `이 추정 위치 사용`: 후보를 확인하고 지도·길찾기·공유에 사용합니다. 넓은 오차 범위는 사용자 확인 없이 경로 시작점으로 사용하지 않습니다.

## 신호 처리

브라우저 Geolocation `watchPosition`에 `enableHighAccuracy: true`, `maximumAge: 0`을 지정합니다. OS가 제공하는 GPS·Wi-Fi·기지국 등의 융합 위치를 사용하며, 웹앱이 주변 Wi-Fi 목록이나 비콘 신호를 직접 읽는 것은 아닙니다. 공급자 선택은 기기와 브라우저에 달려 있습니다.

`geo.js`는 오래된·중복된·유효하지 않은 측정과 갑작스러운 점프를 걸러냅니다. 새 지점으로 크게 이동한 신호는 두 번 일관되게 수신되어야 재획득합니다. 짧은 시간창에서 오차와 최근성으로 가중 평균하되, 반복 수신이 독립 표본이라는 가정을 하지 않아 오차를 표본 수의 제곱근만큼 줄이지 않습니다. 정확도 수치가 커지면 핀과 경로의 신뢰도도 낮춥니다.

마지막 추정은 60초가 지나면 마지막 위치로 표시하고 새로운 경로의 자동 출발점으로 사용하지 않습니다. 새 신호가 지도 밖이거나 너무 부정확할 때도 기존 점을 현재 위치로 보이지 않게 합니다. 백그라운드에서는 위치 구독과 움직임 보조를 멈추고, 돌아오면 사용자가 켜 둔 위치 구독만 다시 시작합니다. `위치 추적 중지`는 구독과 센서를 모두 중지합니다.

## 지리 좌표와 조감도 변환

`data/georeference.json`에는 원본 가이드맵 번호와 연결한 OpenStreetMap 좌표 기준점 28개가 있습니다: 1F 19개, 매직아일랜드 5개, 4F 3개, 2F 1개. 개별 OSM 원본 URL과 데이터 시각을 보존합니다. 변환은 최소 세 개의 비일직선 기준점이 있어야 가능합니다.

- 지리 좌표를 파크 주변의 동·북 방향 미터 좌표로 바꿉니다.
- 인접 기준점에 높은 가중치를 둔 affine 최소제곱 변환으로 PDF 좌표를 추정합니다.
- 변환의 Jacobian으로 기기 오차를 조감도상의 타원 범위로 옮깁니다.
- 지도 변형·시설 중심과 입구의 차이를 고려해 별도의 보수적 여유 범위를 더합니다. 1F·매직아일랜드 50m, 검증 여분 기준점이 없는 4F 80m가 기본입니다. 이는 현장 검증한 정확도나 통계적 95% 신뢰구간이 아닙니다.
- 기준점 영역에서 너무 멀리 벗어나거나 PDF 경계를 벗어난 위치는 표시하지 않습니다. 가까운 통로에 억지로 붙이지 않습니다. 최근 사용자가 확인한 위치 보정값이 있으면 일정한 GPS 편차를 보정할 수 있습니다.

OSM의 자이로스핀 두 좌표는 약 109m, 환타지드림 두 좌표는 약 19m 차이가 나므로 두 종류 모두 초기 변환에서 제외했습니다. 수정일이 최근이라는 이유로 하나를 택하지 않았습니다. 1F 기준점의 단일 affine 교차 검증 편차는 중앙값 약 23m, 최대 약 49m였습니다. 이 수치는 모델과 자료 간 불일치이며 실내 위치 정확도를 측정한 수치가 아닙니다.

## 선택형 걸음 보조

`걸음 보조 켜기`를 누른 경우만 가속도와 절대 나침반 방향을 받습니다. 필요한 기기는 센서 권한을 별도로 요청합니다. GPS 신호가 10초 이상 끊기면, 최근 위치와 지도 변환을 기준으로 0.65m의 가정 보폭을 사용합니다. 최대 30초·35걸음으로 제한하고 이동할수록 추정 범위를 넓힙니다. 기기가 수평에 가깝지 않거나 절대 방향 신호가 없거나 오래되면 보완하지 않습니다. 실내 자성·휴대 방식·보폭 차이 때문에 선택형 실험 기능이며, 층 이동이나 장시간의 신호 단절을 해결하지 않습니다.

## 개인정보와 검증

GPS, 보정점, 센서 값은 메모리에만 존재합니다. 서버 전송·분석 수집·브라우저 영구 저장을 하지 않습니다. 사용자가 명시적으로 위치 공유를 누른 경우에만 지도 좌표·층·추정 여부·범위·수신한 GPS 좌표·시각을 URL fragment로 전달합니다. 추정 위치가 받는 사람에게 확정 위치처럼 표시되지 않도록 공유 형식에 구분을 보존합니다.

검증은 합성 좌표·신호 점프·넓은 오차·권한 거절·층 전환·수동 보정·공유 형식·센서 제한을 대상으로 합니다. 실제 롯데월드 실내에서의 기기별 정확도는 현장 검증이 필요합니다.

참고: [W3C Geolocation](https://www.w3.org/TR/geolocation/), [W3C Device Orientation and Motion](https://www.w3.org/TR/orientation-event/).
